# Site Pulse

Site Pulse is a web application that allows you to run audits on websites to check **security, performance, SEO, and accessibility**. You can view detailed reports and download them as PDFs.

---

## Features

- Run website audits for security, performance, SEO, and accessibility.
- View recent scan history with status and scores.
- Download audit reports as PDF.
- Responsive frontend design.
- Validates URL input to avoid invalid submissions.

---

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, EJS
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **PDF Generation:** Puppeteer
- **Version Control:** Git & GitHub
